# JavaScript ES6 Student Result Dashboard

A simple Student Result Dashboard built as a case study for the **Advanced Frontend Development – JavaScript Refresher** module.

The project demonstrates practical usage of modern JavaScript ES6 features and array methods through both the browser console and a simple interactive HTML webpage.

## Learning Outcomes

This project demonstrates:

- `let`
- `const`
- Arrow Functions
- JavaScript Objects
- `map()`
- `filter()`
- `reduce()`
- `forEach()`
- DOM Manipulation
- Event Handling

## Project Features

- Displays student result records
- Calculates the total number of students
- Calculates the number of students who passed
- Calculates the average student score
- Displays Pass and Fail status
- Filters students based on pass status
- Demonstrates ES6 array methods in the browser console
- Responsive user interface

## ES6 Implementation

### map()

Used to create a new array containing student names.

### filter()

Used to select students whose scores meet the passing requirement.

### reduce()

Used to calculate the total and average scores of the students.

### forEach()

Used to iterate through student records and display them on the webpage and console.

### Objects

Each student is represented as a JavaScript object containing properties such as ID, name, and score.

### let and const

`const` is used for values that do not need to be reassigned, while `let` is used for the filter state because its value changes during user interaction.

### Arrow Functions

Arrow functions are used throughout the project for reusable functions, array operations, and event handling.
